# CyberChess-GAYA
Cyber Chess — GAYA Engine Edition  Xadrez futurista com estética Cyberpunk/Terminal e motor de IA customizado (GAYA v0.6). Desenvolvido em Vanilla JS, o projeto utiliza lógica tática agressiva, sistema de pesos FIDE e interface responsiva com efeitos de partículas e áudio sintético.
